# 书法字库：从字帖扫描页到逐字字图

把书法字帖的扫描页逐字切开，每个字绑定释文，建成「作者 - 字 - 字图」一对多字库（同一个字的多个写法全部保留），并附一个零依赖的静态网站：浏览字图、按字查询、输入一段文字生成临摹字帖（米字格 / 九宫格）。生成字帖可以只用一部帖，也可以按书法家集字（从该书家同一书体的全部作品里取字，楷书、行书各成一库，不混用）；同一个字有多张字图时随机挑一张，可整体「换一批」或点单格换字。

## 方法要点

难点不在识别，在**对齐**：行书字距紧、粘连多，如果先把页面盲切成格子、再给格子配字，切错一格，后面整列都会跟着错。本项目反过来做：每页写了哪些字（释文）是已知的，程序只需要决定**每个字落在哪一段**。

| 环节 | 方法 | 工具 |
|---|---|---|
| 分列 | 墨迹横向投影找各列中心，相邻两列取中线为界 | OpenCV |
| 分割 + 识别 | 按宋体字形估计每个字的高度，生成候选切点；每个候选段送进识别模型，得到「这段是某字」的概率；整页一起做编辑距离式的最优对齐。换列位置允许偏差 ±8 字；释文有、图上没有的记为「缺字」，图上有、释文没有的记为「废段」，出错只影响局部 | PP-OCRv4 识别模型（RapidOCR，约 10 MB，CPU 上运行） |
| 夹注 | 双行小字不参与正文对齐，用人工框，或按墨块自动聚类 | OpenCV |
| 抠图 | 不按横线切，按连通墨块判断归属：主体墨块归所在的字；零散部件（点、八、宀、戈钩）按距离从近到远依次合并（带约束的单链聚类），已属于两个不同字的墨块不会被合并；字轴以外的符号和框线丢掉 | OpenCV |
| 浅墨 | 与本字笔画相连的浅墨并入；沿笔画逐步生长（避开界格线）；按本字自身的墨色定浓淡 | OpenCV |
| 统一规格 | 每页一个统一的方格尺寸（墨迹长边的 90 分位 ÷ 0.86），墨迹居中，**不按单字缩放**，保留原帖中字与字的大小关系 | — |
| 矢量化 | potrace 描出贝塞尔轮廓，输出单色 SVG | potracer |

识别模型**只用于对齐，不决定字的边界**：它认不准帖上的异体字（如把「窪」认成「崖」），用它调边界反而会改错。自动流程里没有用到大模型。

各环节的参数与实验记录见 [`v2/README.md`](v2/README.md)。

## 快速开始

需要 Python 3.10+。

```bash
cd v2
python3 -m venv venv
venv/bin/pip install -r requirements.txt   # 国内可加 -i https://pypi.tuna.tsinghua.edu.cn/simple；potracer 若缺可换阿里云源

# 1. 准备扫描页（扫描图不随仓库分发，需自备）；用环境变量 ZIKU_BOOK 选帖，默认 baomu
venv/bin/python prep_pages.py /path/to/跋王献之保母帖.pdf 1 18   # -> work/pages/p01.png …（宽 2000px）
# ZIKU_BOOK=jcg venv/bin/python prep_pages.py /path/to/九成宫图片目录 1 48   # 拓本：去印、去补纸、反色

# 2. 逐页跑：对齐 -> 夹注定位 -> 抠图 -> 矢量化
./run_pages.sh p01 p02 p03     # 日志在 out3/pNN.log；预览页 glyph/pNN/index.html

# 3. 汇总成字库和网站
venv/bin/python build_site.py  # -> v2/site/（收录 v2/books/ 下全部字帖）
cd site && python3 -m http.server 8801   # 打开 http://localhost:8801/
```

- 对齐时用宋体估字高，默认读取 macOS 的 `/System/Library/Fonts/Supplemental/Songti.ttc`；其他系统请用环境变量 `ZIKU_FONT` 指定一个宋体字体文件。
- 首次运行时，RapidOCR 会使用安装包里自带的识别模型，不需要另外下载。

```

  books/<帖>/          每部字帖一个目录：book.json（元数据、检索别名、不入库清单）、释文；新帖的页面图和产物也放这里
  text/                释文修正与夹注人工框（存在时优先于 work/tokens），逐条依据见 text/README.md
  site_tpl.html        字库网站页面模板
  glyph_tpl.html       单页字图预览模板（米字格、PNG/SVG/原图切换）

```

## 释文格式与原则

`pNN.tokens` 以空格分隔，一个 token 就是一个字。`^字` 表示夹注小字，`-` 和 `@2`、`%` 是早期版本留下的格标记，v2 会忽略。

**照帖上原貌转录**：异体、省笔、自校倒写、缺字符号「口」都按图录，不改成通行写法。本帖已确认的异写有：甎(砖) 觖(缺) 龢(和) 囙(因) 丑(醜) 玄(元) 僊(仙) 峯(峰) 灋(法) 余(餘) 懃(勤)，以及 蹟/跡、云/雲、卅/世 等。最终质量主要取决于释文。

## 无人值守入库与后台

`v2/auto_ingest.py <任务目录>`：给页面图和全文释文，程序自动定参数（拓本/墨迹、缩放、印色）、`seed_text` 全局对齐分页分列、对齐抠图、按几何异常剔除，出 `report.json`。全局对齐对上率 ≥ 85%、缺字 < 5%、无失败页才判「可审核」，否则「需人工」。

`admin/`：后台（上传原帖 → NAS 上的 worker 自动处理 → 预览 → 管理员批准 → 上架线上）。登录要口令 + TOTP，账号只能命令行建；网页进程不持有任何上线凭据，上架由 platform 上的闸门脚本校验后执行。部署说明见 `admin/README.md`。

## 接入新字帖

1. 建 `v2/books/<帖>/book.json`（参照 `jcg`），必填书体 `script`（`楷书` / `行书`，决定集字时归哪个库），拓本加 `"rubbing": true` 和缩放比例 `scale`（让字高约 100px）。
2. `prep_pages.py` 准备页面图。单张长图拼了多段的，在 `book.json` 里用 `crops` 给出各段矩形；题签、残印、水印用 `mask` 涂掉。印章褪色到与纸同色的设 `"red": false`；字放大后长竖笔被当框线删掉的，调大 `frame_line`。纸色偏红的用 `red: {h,s,v}` 收紧印色阈值；有乌丝栏的设 `rules: true`（放大后界栏变粗的加 `rules_before_scale`，纸色不匀的加 `rule_fill: "local"`）；纸上霉点多、印章整块涂会误伤的设 `seal_box: false`；碑文有平阙（抬头、空格）、列中大段空白的设 `full_extent: true`；源图顺序不对用 `order`；反差低的拓本调 `stretch`。
3. 释文：字距规整的楷书/碑帖，把通行释文放进 `baseline.txt`，跑 `seed_text.py` 自动分到逐页逐列，再对图核对；行书字距不匀，要人工按列转录。
4. `run_pages.sh` 跑全流程，看 `glyph/pNN/index.html`，把认不出的残字写进 `drop`，然后 `build_site.py`。
5. 草书需要更多人工。
