# 文徵明《洛神赋》

墨迹小楷，乌丝栏，落款「辛卯三月十日文徵明書」。网络图片 11 张，每张 6 列（末张 5 列）。图片不随仓库分发。

| 文件 | 内容 |
|---|---|
| `book.json` | `scale` 1.6；`red` 收紧朱印颜色阈值（纸色偏红，默认阈值会把整页当印）；`rules` 去界栏；`frame_line` 400；`order` 源图第 6、7 张顺序颠倒，这里换回文序；`skip` 重文号「々」 |
| `baseline.txt` | Wikisource《洛神賦》，只作参考 |
| `text/pNN.tokens` | 对图逐列人工转录，照帖上原貌 |

## 流程

```bash
cd v2
export ZIKU_BOOK=lsf
venv/bin/python prep_pages.py ../原贴/洛神赋-文徵明 1 11   # 放大 -> 印按外接矩形涂纸色 -> 去界栏
./run_pages.sh p01 … p11
```

## 人工核对记录

- 帖文与通行本有出入，照帖录：「京域」作「京師」、「辭曰」作「詞曰」、「楊林」「于巖」「襛纖得中」「永暮慕」（自校，重写「慕」）、「攘皓於神腕」「湍瀨」「怡不」（倒书）、「踊」「爲衛」「北渚」等。
- 重文号「々」单独成字，`skip` 不入库；与重文号粘在一起的 3 个字（峩、浪、綿）不入库。
- 去界栏：细墨（宽 ≤6px）按 x 投影找线位，分段拟合（线略斜且弯），只涂线上细墨；横线转置后同样处理。
- 920 字全部对上，最终 916 图 / 535 字。
