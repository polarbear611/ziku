# 文徵明《千字文》

墨迹小楷，黄纸黑字，落款「嘉靖乙未夏四月二十有九日徵明書」。来源是 9 张网络图片（带「小学生爱写字」水印），每张约 600×2740，图片不随仓库分发。每列 24 字，共 41 列满列、末列 16 字，加标题 3 字和落款 15 字。

| 文件 | 内容 |
|---|---|
| `book.json` | 元数据；`scale` 1.6（列距放大到约 190px）；`red: false`；`frame_line` 400；`mask` 涂掉各图边缘切进来的邻图半列、水印、朱印；`drop` 不入库的字；`alias` 异体检索 |
| `baseline.txt` | 通行释文，取自 [Wikisource《千字文》](https://zh.wikisource.org/wiki/千字文)（公有领域），模板 `{{另|甲|乙}}` 取甲；首尾加标题和落款 |
| `text/pNN.tokens` | 按每列 24 字切分 baseline，再逐页对图把字形改成帖上的写法 |

## 流程

```bash
cd v2
export ZIKU_BOOK=qzw
venv/bin/python prep_pages.py ../原贴/千字文-文徵明 1 9   # mask -> 放大 1.6 倍（墨迹本不反色）
./run_pages.sh p01 p02 p03 p04 p05 p06 p07 p08 p09
```

## 这本帖的特殊设置

- **`red: false`**：印已褪成与黄纸同色相（都约 12），按颜色识别会把整页 46% 当成印、抹掉墨迹。印都在字列外，改用 `mask` 涂掉。
- **`frame_line: 400`**：二值化会删掉长于 120px 的直线（当成框线）；放大后「刂」「門」的长竖笔超过 120，被误删。本帖没有框线，调到 400。
- **释文没用 `seed_text.py`**：它在 p05、p06、p09 漏认了列；本帖格子极规整，直接按每列 24 字切分更可靠。

## 人工核对记录

- 9 页 1018 字全部对上。按图改了 32 处字形，如 召→呂、崗→岡、菓→果、秋→龝、歲→嵗、迩→邇、淬→染、芒→邙、稾→藁、溪→谿、跡→蹟、閑→閒、雕→凋、享→烹、飢→饑、員→圓、床→牀、烝→蒸、嚬→顰、羲→曦、脩→修，以及 p07 的「䟽」→「踈」。
- 10 个字因混入邻字笔画或被邻字抢走笔画而不入库：巨、闕、李、量、聲、虛、職、衡、籃、指（按「字框高于本页中位 1.25 倍 / 明显偏小」筛出 40 个，再逐个看图确认）。最终 1008 图 / 995 字。
