# 颜真卿《多宝塔碑》

拓本剪裱册，网络图片 42 页，每页通常 5 列 × 10 字，黑底白字。图片不随仓库分发。

| 文件 | 内容 |
|---|---|
| `book.json` | `rubbing`、`scale` 0.85、`frame_line` 400；`alias` 把碑上异体（寳、扵、眀、朙、䏻、圎、夲 等）映射到通行字，只用于检索；`drop` 40 个 |
| `baseline.txt` | 维基文库《西京千福寺多寶佛塔感應碑》（CC BY-SA 4.0），保留照碑录的异体，去标点；碑额、撰书人、立石年月、刻工按碑补入 |
| `text/pNN.tokens` | `seed_text.py` 出初稿后逐页对图校正：各页每列字数按图核定，全书 2011 字与 baseline 一一对应 |

## 人工核对记录

- 42 页逐页对过页、列划分，初稿在 p05、p07、p09 等页把字分错了列，已按图改正。
- 40 个不入库：石花残损、与邻字粘连（如「芽聳」「異窮」「誰朙」上下叠在一格）、偈语每章末的双行小字「其一」…「其七」混入正字（輪、念、情、歸 等），以及末页刻工字残缺。
- 最终 1971 图 / 843 字。
