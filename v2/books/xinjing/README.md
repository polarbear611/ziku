# 欧阳询《心经》

拓本，来源是一张网络长图（微博 @中国艺术品收藏），由 7 段拼成：第 1 段是全卷缩略图，第 2、3 段是中等分辨率的分段，第 4–7 段是高清分段，正好覆盖全文。只取第 4–7 段作为 p01–p04。图片不随仓库分发。

| 文件 | 内容 |
|---|---|
| `book.json` | 元数据；`crops` 是 4 段在长图中的矩形；`mask` 是要涂掉的区域（p01 右侧的「唐歐陽詢書」题签和印章，p04 左侧残印与底部水印）；`drop` 是不入库的字 |
| `text/pNN.tokens` | 逐页逐列释文，对图人工转录，照帖上原貌（如「揭帝」不作「揭諦」） |

## 流程

```bash
cd v2
export ZIKU_BOOK=xinjing
venv/bin/python prep_pages.py ../原贴/心经-欧阳询/<长图>.jpg 1 4   # 按 crops 裁段 -> mask -> 去印、反色、放大 1.9 倍
./run_pages.sh p01 p02 p03 p04
```

## 人工核对记录

- 「唐歐陽詢書」这一列不收：带「唐」字，是后人题签，不是欧阳询所写。
- 跋语「貞觀九年十月旦日率更令歐陽詢書」照图录，「旦」「日」两字图上都有。
- p04 咒语的分列与正文不同：右起第 1 列只有「咒曰」，「揭帝揭帝」与「波羅揭帝」在第 2 列上下两段，「波羅僧揭帝」与「菩提薩婆訶」在第 3 列。
- 291 字全部对上。p01 有 10 个字（般、若、波、多、心、經、觀、自、蜜、五）被印章压住或带有印边残迹，不入库，最终 281 图 / 129 字。
