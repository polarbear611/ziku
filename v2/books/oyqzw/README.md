# 欧阳询《千字文》

拓本剪裱册，网络图片 44 张（第 44 张是宋人跋，第 43 张左侧也是跋文，都不收）。每页 4 列 × 6 字，首页为标题「千字文勑員外散騎侍郎周興嗣次韻」。图片不随仓库分发。

| 文件 | 内容 |
|---|---|
| `book.json` | `rubbing`、`scale` 0.85、`frame_line` 400；`mask` 涂掉 p43 的跋文和印；`drop` 34 个残损或串字；`alias` 异体检索 |
| `baseline.txt` | 首行标题 + 文徵明《千字文》同一底本（Wikisource）；本帖缺「治本於農務茲稼穡」8 字（剪裱时缺失），已从释文中去掉 |
| `text/pNN.tokens` | 按每列 6 字、每页 4 列切分，再逐页对图改字形 |

## 流程

```bash
cd v2
export ZIKU_BOOK=oyqzw
venv/bin/python prep_pages.py ../原贴/千字文-欧阳询 1 43
./run_pages.sh p01 … p43
```

## 人工核对记录

- `seed_text.py` 在首页标题和 p28 处错位（p28 缺 8 字），改为按格子切分，43 页全部对上。
- 按图改 26 处字形（貟、呂、為、崑、岡、果、珍、蓋、染、克、競、邙、藁、桼、鑒、踈、凋、墻、烹、圓、煒、牀、弦、妍、曦、琁），另 p39 帖上作「盜賊」，与底本「賊盜」顺序相反，照帖改。
- `frame_line` 400：放大后长竖笔被当框线删掉（如「十」「中」）。
- 34 个字不入库：石花残损、补纸遮挡或混入邻字，清单在 `drop`。最终 973 图 / 962 字。
